Chantier 06 · move_to_cli

Sortir le lancement de Swairm des scripts npm pour en faire une vraie commande swairm, utilisable depuis A-I-D comme depuis le terminal.

Objectif

  • •Une commande unique : swairm run, swairm plan, swairm status
  • •Les options lues dans .aid/config.yaml quand elles existent
  • •Aucune régression sur les runs lancés par A-I-D

Avancement

  • ✓Extraire le parseur d’arguments (src/cli/args.ts)
  • ✓Commande swairm run
  • Commandes plan et status
  • Documentation dans le README

Options de swairm run

OptionRôleDéfaut
--modelModèle du planneropus
--dry-runAffiche le plan sans lancer d’exécuteurnon
--max-executorsExécuteurs en parallèle2

Exemple

bash
swairm run --model sonnet --dry-run
swairm status --json
